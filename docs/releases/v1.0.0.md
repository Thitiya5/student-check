## Summary

Initial production release of **Student Check** for Yangtaladwittayakarn School — a PWA for daily student attendance, history, and reporting, backed by Firestore and Google Sheets.

---

## Highlights

### For teachers

- Login with teacher name + PIN
- Dashboard with today's attendance overview
- Class attendance check with save to Firestore
- History and multi-mode reports (daily, weekly, monthly, semester)
- Student list and student profile
- Offline-capable PWA

### For administrators

- Admin roster management (students, teachers)
- School-wide report access
- Settings and inspection tools
- Behavior points and discipline modules

### Technical

- Vite + Vanilla JS frontend
- Firebase Hosting + Firestore
- Google Apps Script roster API
- Thai / English i18n, light/dark theme
