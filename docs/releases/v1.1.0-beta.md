## Summary

Adds an **admin-only Executive Dashboard** (`#/executive`) for school-wide operational visibility — classroom completion progress, attendance KPIs, grade comparison, and real charts — without modifying the teacher attendance workflow.

---

## What's new

### Executive Dashboard (`#/executive`)

| Feature | Sprint |
|---------|--------|
| Isolated UI foundation (filters, KPIs, table, export placeholder) | 1 |
| Live Firestore read services + enhanced header | 2 |
| Today's Attendance Progress command center | 2.5 |
| Real charts (grade, status, completion donut, top/attention rooms) | 3 |

### Command center (Sprint 2.5)

- Attendance completion % with color-coded progress bar
- Pending classrooms list (max 10 visible)
- Recently completed room + teacher + time
- Operational status summary (✅ / 🟡 / 🔴)

### Charts (Sprint 3)

- Attendance by Grade
- Status Distribution (saved records only)
- Checked vs Pending Rooms
- Top / Attention Rooms (submitted classrooms)

---

## Access control

- **Admins only** — route guard + hidden from teacher nav
- Teachers unchanged

---

## Performance

- **1 Firestore read** + **1 roster read** per executive page refresh
- No additional queries for charts
- Spark-plan friendly

---

## Not included (deferred)

- Executive PDF export (button disabled — “เร็ว ๆ นี้”)
- Monthly / semester / trend executive reports
- Filter wiring to date ranges beyond selected day

---

## Upgrade from v1.0.0

1. `npm run build`
2. `firebase deploy --only hosting:app`
3. No Firestore migration required
4. No GAS changes required for executive module

---

## Breaking changes

**None** for teachers or existing admin workflows.

---

## Known issues

- `package.json` still shows `3.1.0` — governance version is `v1.1.0-beta`
- Executive KPI cards may count unsubmitted students as absent; completion section uses separate rules
- Roster (GAS) failure blocks executive page — use Retry after fixing GAS
