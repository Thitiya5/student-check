## Summary

Stabilization release focused on **attendance save reliability**, **School Overview access for teachers with read caching**, and **admin bulk discipline restore** with PIN and audit trail. Attendance save flow and Firestore attendance schema unchanged.

---

## P0 — Attendance save hotfix

- Batched writes with timeout; non-blocking point sync after save
- Save button disabled during submit; no auto-resync on class open
- Submission markers for operational tracking

---

## P1 — School Overview

| Item | Detail |
|------|--------|
| Access | All logged-in teachers (read-only) |
| Data | School-wide attendance + roster per selected date |
| Cache | Memory + sessionStorage, 3 min TTL, keyed by date |
| Refresh | Manual “โหลดใหม่” button |
| PDF | Admin-only (unchanged) |
| Dashboard | Removed at-risk alerts + duplicate room-checked section |
